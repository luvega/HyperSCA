# Methods protocol v2.1 closure review

The v2.1 pilot audit is frozen as `pilot_failed_no_release`. No release or
promotion is authorized by this record.

The five frozen blocking reasons are:

1. OSTA has one biological sample per platform stratum.
2. The CausalBench mean-difference comparator has no eligible relations.
3. The OSTA hierarchy-attribution confidence interval crosses zero.
4. CausalBench direction-attribution fails for both `k562_to_rpe1` and
   `rpe1_to_k562`.
5. The v2.1 redesign has already been used and cannot be silently redesigned
   again.

This is a closure of the audited v2.1 evidence, not a new pilot or a release
decision in favor of release.
