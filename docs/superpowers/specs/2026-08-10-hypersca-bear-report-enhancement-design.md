# HyperSCA 报告 Bear 证据融合式完善设计

**日期：** 2026-08-10  
**状态：** 已批准的实施设计

## 1. 目标

在保留现有工程审计、科学成熟度评估、外部研究矩阵和 P0–P3 路线图的前提下，使用本机 Bear Research Skills 的真实 SciMaster 检索，为报告增加三个当前相对薄弱的证据面：

1. HyperSCA 核心研究构想与既有工作的撞车程度；
2. 相对安静方向是否存在可独立支撑的文献基础；
3. 对相对安静方向最有威胁的反证、边界条件和方法批评。

完善后的报告仍是定向范围综述与项目审计，不升级为系统综述，也不把计算候选解释为已验证药物机制。

## 2. 核心研究构想

Bear 检索使用以下压缩构想作为统一语义锚点：

> HyperSCA 旨在建立一个可审计的单细胞—空间多组学研究平台，联合真实扰动、因果网络、反事实生成与空间传播，预测药物或靶点的细胞自主效应和邻域效应，并以分层证据门控决定候选是否进入主排名。

检索同时使用中文概念拆解和英文查询，但论文、作者和结论只能来自本次 `sci search` 返回的记录。

## 4. Bear 工作流

使用 `bear-propose` 的固定顺序，共执行约 15 次检索。

### 4.1 Phase A：撞车检测

从六个正交角度宽扫：

1. 字面构想：单细胞、空间组学、因果推断、药物靶点发现的一体化平台；
2. 方法中心：causal graph、counterfactual、spatial propagation、perturbation modeling；
3. 问题中心：预测细胞自主与邻域药物/遗传扰动效应；
4. 结论中心：空间生态位特异的药物机制和靶点排序；
5. 相邻领域：virtual tissue、digital twin、multicellular response；
6. 抢发者标题：2025–2026 spatial perturbation、causal single-cell、drug response 预印本。

六次宽扫使用 `ultra_low`；选择五个信息量最高的角度以 `low` 复跑。合并后按 DOI、PMID、标题规范化结果去重。

### 4.2 Phase B：安静区识别与支撑

根据 Phase A 的四层分类，选取最多两个相对安静且与 HyperSCA 现有资产一致的角度。每个角度执行一次 `low --limit 15` 检索。支撑强度分为：

- 直接支撑：研究任务、数据与评价终点同时对应；
- 部分支撑：支持关键组件或假设，但不覆盖完整任务；
- 间接相关：只支持必要性或邻近机制；
- 排除：摘要不支持正文拟写主张。

### 4.3 Phase C：潜在挑战

针对安静区核心主张分别检索：

1. 直接矛盾或失败证据；
2. 方法批评、识别性、泛化、数据泄漏或验证不足。

两次检索均使用 `low --limit 15`。每个高威胁挑战必须对应至少一项 HyperSCA 设计响应，无法响应的内容进入限制而不是路线图承诺。

## 7. 证据与写作规则

- 每条新增论文信息必须能回溯到本次 SciMaster JSON 和 BibTeX；
- DOI 页面、PubMed 或出版社页面用于复核关键元数据，但不能用未检索来源悄悄补足 Bear 结果；
- 预印本、同行评议论文、综述和数据资源分别标注；
- 将“新颖性”改写为“本次检索中的相对安静区”；
- 将“因果机制”限制为 E2/E3 证据允许的表述；
- 任何高性能数字都同时记录数据集、任务、对照和验证范围；
- 每段第一句给出段落主旨，段内只承载一个中心消息；
- 新增结论必须进入主张—证据映射，未充分支持的结论降级或删除。
