# HyperSCA v0.7.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the audited Methods v3 tree as a bilingual, illustrated HyperSCA v0.7.0 release through the protected GitHub `main` branch.

**Architecture:** Build a new linear release branch from `origin/main`, import the already-verified `eb2b621` tree as one snapshot commit, then layer release-only documentation, metadata, image, and CI timeout changes on top. GitHub receives the branch through a pull request; after the required Python 3.10 check succeeds, merge by rebase and tag the resulting protected `main` commit.

**Tech Stack:** Git worktrees, Python 3.10, setuptools/`pyproject.toml`, pytest, GitHub Actions, GitHub CLI, built-in `$imagegen`, Markdown.
