# HyperSCA v0.7.0

[中文](#中文) | [English](#english)

## 中文

### 版本定位

HyperSCA v0.7.0 是面向可审计方法比较与空间扰动桥接的研究版本。它仍处于
Alpha 阶段：本次发布冻结分析约定、证据边界和可重放工件，但不把软件验证等同于
生物学或临床验证。

### 主要更新

- 新增 Methods v3 比较协议，明确数据划分、统计单位、覆盖率、暂不判断比例和
  证据升级条件。
- 新增按整只动物隔离的空间扰动桥接流程，覆盖候选登记、近邻构建、效应评分、
  简单对照方法以及运行证据发布与集合检查。
- 冻结 HyperSCA、匹配欧氏空间因果对照、`own_only` 和距离衰减审计对照的角色与
  计算资源边界。
- 增加导入架构、属性测试、不可变身份、输入重放和失败关闭检查，减少测试脚本或
  结果摘要绕过科学约定的风险。

### 验证与证据边界

Methods v3 的合成夹具、契约、证据发布和端到端重放已经通过 Python 3.10 测试。
真实 GSE274447 空间扰动 pilot 没有运行，因为登记的外部队列根目录在执行环境中
不存在。v0.7.0 只发布这一 stop-gate 事实；没有虚构 pilot 结果、预测能力工件或
模块升级结论。

### 兼容性

- Python：`>=3.10`
- Python 包版本：`0.7.0`
- CPU 核心安装：`python -m pip install -e ".[dev]"`
- 完整科研栈继续使用 `requirements.txt` 和按需 GPU/PyG 依赖。

## English

### Release scope

HyperSCA v0.7.0 is a research release focused on auditable method comparison and
the spatial-perturbation bridge. It remains alpha software: this release freezes
analysis contracts, evidence boundaries, and replayable artifacts, but software
verification is not presented as biological or clinical validation.

### Highlights

- Adds the Methods v3 comparison protocol with explicit data splits, statistical
  units, coverage, abstention, and evidence-promotion conditions.
- Adds a whole-animal-isolated spatial-perturbation bridge spanning candidate
  registration, neighborhood construction, effect scoring, simple comparators,
  and run-evidence publication and collection checks.
- Freezes the roles and resource budgets of HyperSCA, the matched Euclidean causal
  comparator, `own_only`, and the distance-decay audit comparator.
- Adds import-architecture, property, immutable-identity, input-replay, and
  fail-closed checks to reduce scientific-contract bypasses through tests or
  summary artifacts.

### Verification and evidence boundary

The Methods v3 synthetic fixtures, contracts, evidence publication, and end-to-end
replay have passed the Python 3.10 test gate. The real GSE274447 spatial-
perturbation pilot was not run because the registered external cohort root was
absent from the execution environment. v0.7.0 publishes only this stop-gate fact;
it does not fabricate pilot outcomes, predictor-capability artifacts, or promotion
claims.

### Compatibility

- Python: `>=3.10`
- Python package version: `0.7.0`
- Core CPU install: `python -m pip install -e ".[dev]"`
- The extended research stack continues to use `requirements.txt` plus optional
  GPU/PyG dependencies where needed.
